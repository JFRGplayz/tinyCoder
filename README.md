
# TinyCoder

Tiny is a small experimental language model built from scratch.

## Features

- Custom automatic differentiation
- Causal self-attention
- Token and positional embeddings
- Feed-forward neural network
- Backpropagation
- Adam optimiser
- Character-level tokenisation
- Local conversational storage
- User-provided training examples

## Languages

- JavaScript
- HTML
- CSS
- Python
- TypeScript

## Dependencies

None.

## Hosting

Hosted using GitHub Pages.

## Model

Tiny v0.1 is a single-head, single-block experimental
Transformer.

All neural network operations are implemented
without external machine-learning libraries.

## Important

Tiny is an experimental model, not a production
coding assistant. Its initial weights are random.
Training examples are currently learned through
next-character prediction.
